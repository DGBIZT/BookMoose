# API для управления библиотекой

1. Описание:
```
 Разработан REST API для управления библиотекой. API предоставляет возможность для управления книгами, жанрами, авторами и пользователями, 
 а также отслеживание выдачи книг пользователям. Для реализации API использован Django Rest Framework (DRF).
```
2. Клонируйте репозиторий:
```
    1) HTTPS 
            https://github.com/DGBIZT/BookMoose.git
    2) SHH
            git@github.com:DGBIZT/BookMoose.git
```
###### №1 Разработка сервиса
```
    1. Реализация API для управления библиотекой
    2. Обеспечить аутентификацию и авторизацию пользователей с использованием JWT токенов.
    3. Обеспечить возможности для управления книгами, жанрами и авторами.

```
###### №2 Функционал API
```
    1. Регистрация и аутентификация пользователей:
        * Реализована система регистрации и аутентификации пользователей.
        
    2. Управление книгами:
        * Создание, редактирование и удаление книг.
        * Получение списка всех книг.
        * Поиск книг по различным критериям (название, автор, жанр и т.д.).
        
    3. Управление авторами:
        * Создание, редактирование и удаление авторов.
        * Получение списка всех авторов.
        
    4. Управление жанроми:
        * Создание, редактирование и удаление жанров.
        * Получение списка всех жанров.
        
    5. Выдача книг: 
        * Запись информации о выдаче книги пользователю.
        * Отслеживание статуса возврата книги.
        
    6. Ограничение доступа
        Описание ролей и прав доступа:
            1) Пользователь
                    * Создание, просмотр, редактирование и удаление своих книг, жанров и авторов.
            2) Админ
                    * Просмотр всех книг и пользователй.
                    * Выдача книг, отслеживание и примем.
                    * Блокировка пользователей сервиса.???????????????????????
                    * Удаление, редактирование
```
###### №3 Практическая часть
```
    1) Создайте БД в PostgreSQL (CREATE -> DATABASE -> SAVE)
    2) В pycharm клонируете репозиторий указанный выше.
    3) Переименнуйте файл .env.exemple в .env и внесите свои данные.
    4) Введите команду python manage.py migrate последовательно.
        * python manage.py migrate authors
        * python manage.py migrate generes
        * python manage.py migrate books
        * python manage.py migrate loans
        * python manage.py migrate
        Благодаря этому вы сконектитесь с вашей БД.
    5) Обязательно обновите все зависимости: введите команду poetry update
    
    6) Далее будут описаны несколь команд по заполнению проекта, Вы также можете самостоятель внести свои данные в файлах 
        add_generes.xlsx, add_generes.xlsx, authors.xlsx которые находятся в папке data.
        Команды:
            
            * python manage.py add_user
                - Создастся пользователь-администратор с входными данными email = 'admin@go.pro' и password '1234'
           
            * python manage.py import_genres data/genres.xlsx --user-id 1
                - Заполняется таблица genres, данные беруться из Excel файла add_generes.xlsx, который находится в папке data.
                  Данный файл можно самому заполнять.
                  
            * python manage.py fill_authors
                - Заполняется таблица authors, данная команда для быстрого заполнения, для демонстрации проекта
                
            * python manage.py import_authors data/authors.xlsx --user-id 1
                - Заполняется таблица authors, данные беруться из Excel файла authors.xlsx, который находится в папке data. 
                  Данный файл можно самому заполнять.
            
            * python manage.py fill_books data/books.xlsx --user-id 1
                - Заполняется таблица books, данные беруться из Excel файла books.xlsx, который находится в папке data. 
                  Данный файл можно самому заполнять.
                
      
    7)  Установите Redis Server (Remote Dictionary Server) — это высокопроизводительная система управления базами данных (СУБД) с открытым исходным кодом,
     которая хранит данные в оперативной памяти в формате ключ-значение.  
        Запустите  redis-server.exe и не закрывайте покане не прекратите работать с приложением
        В командной строке введите команду redis-cli далее select 1 -  выбираем базу данных внутри Redis.  
                       
```
###### №3 Команды в Postman
```

        * POST http://127.0.0.1:8000/users/register/
          {
            "username": "Click",
            "email": "click@gmail.com",
            "password": "1234"
          }

        * POST http://127.0.0.1:8000/users/login/
          {
            "email": "click@gmail.com",
            "password": "1234"
          }

        В Body во вкладке {} JSON появится две строчки:

              "access": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.
                  eyJ0b2tlbl90eXBlIjoiYWNjZXNzIiwiZXhwIjoxNzYyODg2MjgwLCJpYXQiOjE3NjI4ODUzODAsImp0aSI6ImI3YzQzODY2YmFjMDRjNmM4NDM4NzkxMGQzZWUzMTM0IiwidXNlcl9pZCI6IjEifQ.

    3) Получить экземпляры книг
        * GET http://127.0.0.1:8000/books/instances/
    
    4) Получить экземпляр книги
        * GET http://127.0.0.1:8000/books/instances/id/ 
        id книги вы увидите после команды получить экземпляры книг

            "edition": "Издательство",
            "available_copies": "Доступные копии",
            "total_copies": "Всего копий",
            "copy_id": "PH001232"
          }
   
   7) Обновление количества экземпляров книг:
        * POST http://127.0.0.1:8000/books/books/11/add_copies/ 
          {
            "count": 2  // Создать 2 экземпляра
          }
   
   8) Выдача книги:
      * POST http://127.0.0.1:8000/loans/loans/
        {
          "book_instance": 1, // ID экземпляра
          "user": 2          // ID пользователя, которому выдаём книгу
          "due_date": "2025-11-13T00:00:00Z",  // срок возврата (ISO 8601)
          "notes": "Книга выдана на 7 дней"
        }
   
   9) Вернуть книгу:
      * PATCH http://127.0.0.1:8000/loans/id/
        {
          "is_returned": true
        }
   
   10) Посмотреть список выдачи книг:
      * GET http://127.0.0.1:8000/loans/loans/
   
   Добавить, обновить, посмотреть и удалить можно аналогично примеру книг.
   Жанр адрес: http://127.0.0.1:8000/genres/genres/
   Авторы адрес: http://127.0.0.1:8000/authors/authors/
```        
###### №4 Работа с Docker
```
    Приложение BookMoose запускается в Docker‑контейнерах.
    
    * Требования:
        Перед запуском убедитесь, что у вас установлены:
            - Docker (версия ≥ 20.10)
            - Docker Compose (версия ≥ 1.29)
    
    * Структура Docker‑файлов:
        В проекте используются:
            - Dockerfile` — инструкция по сборке образа приложения.
            - docker-compose.yml` — конфигурация сервисов (приложение, БД и т.п.).
    
    * Сборка и запуск
        Соберите образы и запустите контейнеры:
            - docker compose up --build --force-recreate -d
  
```
